New Tab icons are generated in newtab/public:
- newtab-icon-16.png, newtab-icon-32.png, newtab-icon-48.png, newtab-icon-128.png
- cws-newtab-icon-16.png, cws-newtab-icon-32.png, cws-newtab-icon-48.png, cws-newtab-icon-128.png, cws-newtab-icon-300.png

The cws-newtab-*.png files are Chrome Web Store manifest icons with 96x96 artwork inside a 128x128 transparent canvas.

These should be the Brute Bookmarks logo/icon in a square format.
For store listings, also create a 440x280 promotional tile.
