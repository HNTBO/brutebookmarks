Extension icons are generated in extension/public:
- quicksave-icon-16.png, quicksave-icon-32.png, quicksave-icon-48.png, quicksave-icon-128.png, quicksave-icon-300.png
- newtab-icon-16.png, newtab-icon-32.png, newtab-icon-48.png, newtab-icon-128.png, newtab-icon-300.png
- cws-quicksave-icon-16.png, cws-quicksave-icon-32.png, cws-quicksave-icon-48.png, cws-quicksave-icon-128.png, cws-quicksave-icon-300.png
- cws-newtab-icon-16.png, cws-newtab-icon-32.png, cws-newtab-icon-48.png, cws-newtab-icon-128.png, cws-newtab-icon-300.png

The legacy icon-*.png files mirror the quick-save artwork for compatibility.
The cws-*.png files are Chrome Web Store manifest icons with 96x96 artwork inside a 128x128 transparent canvas.

These should be the Brute Bookmarks logo/icon in a square format.
For store listings, also create a 440x280 promotional tile.
